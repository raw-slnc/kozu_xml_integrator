# 公図XML統合アルゴリズム v2 設計書

## 基本方針

### 優先順位（高→低）

1. **公共座標データ** - 絶対不変（移動・回転・スケール・変形すべて禁止）
2. **市町村境界** - 信頼できる外枠制約
3. **XML内トポロジー** - 隣接関係維持
4. **地番マッチング** - XML間の位置関係決定
5. **大字境界** - 参考配置のみ（厳密フィット対象外）

### 精度レベル

| データ | 精度 | 扱い |
|--------|------|------|
| 公共座標（測量済み） | ★★★ | 固定アンカー |
| 市町村境界 | ★★★ | 外枠制約 |
| 大字境界（森林計画図由来） | ★☆☆ | 参考表示のみ |

## 処理フロー

### STEP 1: データ読込と分類

```
入力:
  - XMLデータベース（SpatiaLite）
  - 市町村境界シェープ
  - 大字境界シェープ（任意）

処理:
  1. 各XMLを座標系タイプで分類
     - 公共座標系 → アンカー候補
     - 任意座標系 → 変換対象

  2. 大字属性の付与（t_fude_poly.oaza_name）
```

### STEP 2: 大字内XML統合

```
各大字について:

  1. 公共座標XMLを固定アンカーとして配置
     - 位置・形状は一切変更しない

  2. 任意座標XMLをアンカーに接合
     a. 共通地番を検索
     b. 共通地番の重心位置でヘルマート変換パラメータを計算
     c. 変換を適用（移動・回転・スケール）
     d. XML内トポロジーは維持

  3. 接合できないXMLの処理
     - 大字境界の重心方向に概略配置
     - 「LOW信頼度」フラグを付与
```

### STEP 3: 市町村境界へのフィッティング

```
制約:
  - 公共座標データは固定（TPS制御点として錨）
  - 任意座標データのみ変形対象

処理:
  1. 市町村境界から制御点を抽出
  2. 公共座標の頂点を固定制御点として追加（移動量=0）
  3. TPS（Thin Plate Spline）変形を計算
  4. 任意座標データに変形を適用
```

### STEP 4: 平準化（Leveling）

```
重要な制約:
  - 公共座標データは完全な境界を持つ
  - 公共座標データは平準化の対象外
  - 重なり/隙間がある場合、任意座標側のみで調整

反復処理（収束まで）:

  1. 重なり検出
     - 隣接筆間のintersectionを計算
     - 面積 > 閾値 なら重なりあり

  2. 調整量の計算
     - 公共座標 vs 任意座標の場合 → 任意座標側が100%負担
     - 任意座標 vs 任意座標の場合 → 両者で分担
     - 各筆の調整量 = 重なり面積 × 分担率 × 減衰係数

  3. 緩やかな縮小
     - 任意座標筆のみを重心方向に調整量分だけ縮小
     - 急激な変形を防ぐため1回あたりの調整量に上限

  4. 収束判定
     - 総重なり面積 < 閾値 なら終了
     - 最大反復回数に達したら警告付きで終了
```

### STEP 5: 品質検証と出力

```
検証項目:
  - 市町村境界からのはみ出し
  - 残存する重なり
  - 孤立XML（どこにも接合できず）
  - トポロジー異常

出力:
  - GeoPackage（大字別レイヤー）
  - 品質フラグ属性
    - reliability: HIGH / MEDIUM / LOW
    - needs_review: true / false
    - review_reason: はみ出し / 重なり / 孤立 / etc.
```

## データ構造

### 品質フラグ

```sql
-- t_fude_poly に追加する属性
ALTER TABLE t_fude_poly ADD COLUMN reliability TEXT;      -- HIGH/MEDIUM/LOW
ALTER TABLE t_fude_poly ADD COLUMN needs_review INTEGER;  -- 0/1
ALTER TABLE t_fude_poly ADD COLUMN review_reason TEXT;    -- 理由
ALTER TABLE t_fude_poly ADD COLUMN transform_method TEXT; -- 変換方式
```

### 信頼度の定義

| 信頼度 | 条件 |
|--------|------|
| HIGH | 公共座標、または公共座標に直接地番接合 |
| MEDIUM | 地番マッチングで間接接合（チェーン経由） |
| LOW | 大字境界ガイドのみで配置、または孤立 |

## 制約事項

1. **公共座標は絶対不変**
   - いかなる場合も変形しない
   - 他のデータがこれに合わせる

2. **トポロジー優先**
   - 隣接関係は維持
   - 変形は緩やかに

3. **人間が最終判断**
   - 自動処理は8割の精度を目指す
   - 残り2割は人間がQGISで調整
